STL Stereo Camera Renderer

Upload an STL file and get two images of it, rendered from two cameras that are both distance d from the object and o apart from each other (like a stereo camera pair).

Batch Render from CSV

Point this at a CSV file already on this machine, with a header row of filename,d,o,rx,ry,rz (rx/ry/rz optional, default 0). Each filename is resolved relative to the CSV's own folder. Output goes into a new <csv name>_output folder next to the CSV, with one subfolder per resolution (64x64, 128x128, 256x256), each containing <stl name>_row<N>_left.png / _right.png (the CSV row number keeps names unique if the same STL appears in multiple rows) plus a manifest CSV that reproduces the original rows with two appended columns, left and right.
