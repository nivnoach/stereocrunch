STL Stereo Camera Renderer

Upload an STL file and get two images of it, rendered from two cameras that are both distance d from the object and o apart from each other (like a stereo camera pair).

Object rotation, applied in order pitch → yaw → roll (degrees):

1. Folder Preview

Point this at a folder of raw STLs (default orientation, no CSV needed yet). Review a thumbnail per file, skip ones you don't want, and align misaligned ones in the 3D viewer — each file's default distance is auto-computed from its own size. Save your selections as a base CSV, one row per kept file.

2. Generate Permutations

Takes a base CSV (e.g. from Folder Preview) and expands each row into several rows with distance randomized within a multiplier range of that row's own d. Rotation is copied unchanged.

3. Batch Render from CSV

Point this at a CSV file already on this machine, with a header row of filename,d,o,rx,ry,rz (rx/ry/rz optional, default 0). Each filename is resolved relative to the CSV's own folder. You'll land on a preview page first, with a thumbnail per row to check alignment, checkboxes to skip rows, and a link to fix a misaligned row's rotation in the 3D viewer before the batch actually runs. Output goes into a new <csv name>_output folder next to the CSV, with one subfolder per resolution (64x64, 128x128, 256x256), each containing <stl name>_row<N>_left.png / _right.png (the CSV row number keeps names unique if the same STL appears in multiple rows) plus a manifest CSV that reproduces the original rows with two appended columns, left and right.
