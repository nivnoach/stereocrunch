STL Rotation Viewer

Load an STL, drag it to rotate, and read off the exact rx, ry, rz values to use in a CSV row for batch rendering. Rotation here uses the identical pitch→yaw→roll convention as the render/batch features, applied about the object's own center, so what you see is exactly what you'll get.

Drag horizontally to yaw (ry), vertically to pitch (rx). Use the roll field for rz.
